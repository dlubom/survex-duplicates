# Changelog

## [1.0.0] - 2026-10-26

First public release of Survex Duplicate Detector.

- Native command-line detection of overlapping survey legs in Survex models and text dumps.
- Exact endpoint comparisons, relative and absolute tolerances, SPLAY/DUPLICATE filters, and ordered 47-column CSV reports.
- Six portable ZIP packages: Linux, macOS and Windows on x86-64 and ARM64, with source provenance and SHA-256 checksums.
- Complete KATASTER example, eight reference reports, usage documentation and separate software/data license notices.
- Independent oracle, regression tests, fuzzing, 27 curated mutation checks and native package validation on all six targets.
