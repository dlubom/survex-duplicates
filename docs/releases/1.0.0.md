# 1.0.0 — Initial release

The first public release of Survex Duplicate Detector provides a native command-line tool for finding geometrically overlapping survey legs in adjusted cave models.

- Read Survex `.3d` models through `dump3d`, or process text dumps directly without installing Go, Python or Survex.
- Find matching legs in either orientation using exact endpoint comparisons, a default 5% relative tolerance, or an explicit absolute tolerance. Control SPLAY and acknowledged DUPLICATE legs with dedicated filters.
- Export ordered results to a 47-column CSV, including station names, survey metadata and both endpoint errors. Existing output files are protected unless replacement is requested.
- Download native ZIP packages for Linux, macOS and Windows, each on x86-64 and ARM64. Packages include version information, source provenance and SHA-256 checksums.
- Try the complete KATASTER example with preserved inputs, attribution and eight reference reports. The default report contains 218 candidate pairs, or 60 with SPLAY legs excluded.
- Validation includes an independent exhaustive oracle, regression tests, fuzzing, 27 curated mutation checks and native execution of packaged programs on all six targets.

A geometric match is a candidate for survey review; it does not establish that a measurement should be removed. The software is MIT licensed. Bundled survey data and derived reports retain their separate CC BY-SA 4.0 attribution.
